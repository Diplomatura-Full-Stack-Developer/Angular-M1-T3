### Como ejecutar la tarea:

1. Clonar el repositorio:

```bash
git clone https://github.com/Diplomatura-Full-Stack-Developer/Angular-M1-T3

```

2. Instalar las dependencias:

```bash
npm install
```

3. Ejecutar la aplicación:

```bash
ng serve
```
